# Системное окружение
- **ОС**: NixOS
- **Управление пакетами**: Для установки новых утилит или зависимостей использовать `nix-env` или `nix-shell`. Никогда не использовать `apt`, `yum` или `pacman`.

# Процесс работы (GitHub Flow)
- **Строгое правило**: НИКОГДА не коммитить и не пушить изменения напрямую в ветку `main`.
- **Ветки**: Под каждую новую задачу (Issue) создавать отдельную ветку от `main` (формат: `fix/...`, `feat/...`, `docs/...`).
- **Сохранение**: Регулярно фиксировать изменения понятными коммитами по стандарту Conventional Commits.
- **Проверка**: Отправлять код на сервер в рабочую ветку и обязательно создавать **Pull Request**. Вливать код в `main` может только напарник после проверки.
