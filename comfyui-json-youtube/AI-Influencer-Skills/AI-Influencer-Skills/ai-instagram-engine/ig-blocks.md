# Instagram blocks — Baddie (headless fallback)

> Primary path = **you (Claude) author the feed** from `ig-library.md`. This file
> is the **headless fallback** for `--ig N` (cron / no Claude in the loop) — a dumb random mixer.

`py generate.py --ig N` combines a random **template × outfit × lighting** into N unique
prompts — fresh combinations every run, so the feed never repeats. Identity comes only
from the anchors (face anchor = reference #1); the prompts stay identity-free.

Aesthetic: **hot, confident "baddie" iPhone content** — real amateur-iPhone look, but with
attitude. Every template carries a confident cue (hip out, chin-down-eyes-up,
over-the-shoulder, lip bite, smirk, power stance, one hand in her hair, body-aware
framing). Still SFW (clothed). The bust/body lock is appended automatically. `{outfit}`
and `{light}` are filled in automatically — add or edit any line below.

GLAM = styling only (glossy lips, winged eyeliner and lashes, gold hoops, long nails,
fine jewelry). NEVER write hair / eye color / skin tone / body — that is identity and
comes ONLY from the anchor images.
