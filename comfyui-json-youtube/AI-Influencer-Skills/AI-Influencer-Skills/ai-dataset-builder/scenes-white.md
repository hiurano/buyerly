# Dataset — WHITE background pack (clean cutout reference)

White-background version of the identity pack + 360° rotation, ported from the
Dataset Prompt Library (SREF-W / S360W). Pure white flattens skin, so every prompt
here carries the skin-realism clause — do not remove it on this pack.

This pack uses the library's canonical outfit (black fitted ribbed t-shirt + blue
straight-leg jeans) so the rotation is uniform regardless of what the anchors wear.
Swap the outfit phrase if the anchors' own outfit should be kept instead.

Run: `py generate.py --character <name> --scenes scenes-white.md`
(optionally `--blocks face` or `--blocks 360-white`)
