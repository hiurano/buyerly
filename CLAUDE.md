# Claude instructions for Buyerly

Follow [`AGENTS.md`](AGENTS.md) for repository workflow and safety rules.

For every frontend or visual change, you **must** read and follow [`docs/UI_CONTRACT.md`](docs/UI_CONTRACT.md) and [`docs/DESIGN_SYSTEM.md`](docs/DESIGN_SYSTEM.md). Production tokens live in [`frontend/src/styles/tokens.css`](frontend/src/styles/tokens.css), shared React primitives live in [`frontend/src/ui/`](frontend/src/ui/), and page-local replacements are forbidden.
